Board Game Log – Support

Welcome! This page provides basic help and contact information for the Board Game Log app.

Getting Started

  1. Create a new game: On the main screen, open the game list and tap Start a New Game.
  2. Add players: Enter player names manually or use a saved player group.
  3. Set game details: Choose the number of players, game type, speed, and start time.
  4. Track the session: Use the in-game views and dice screen (optional) while you play.
  5. End the game: Enter final scores, achievements, and save the results.

Common Questions

How do I delete a game?

Open the game history, select the game, and use the delete option from the menu or toolbar. Deleting a game removes it from your history on that device.

Where is my data stored?

All game data, player names, and photos are stored locally on your device. We do not operate servers for Board Game Log.

Does the app use the internet?

The core features do not require an internet connection. If you enable any local network features (for example, a local dice remote), communication happens only on your local network between your devices.

How do I report a bug or request a feature?

Please send an email with a short description, your device model, and iOS version.
